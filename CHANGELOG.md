# Changelog

Notable changes to LocalMind. Dates are release dates.

## Unreleased

### Added
- Shortcuts actions — **Ask LocalMind** (prompt in, answer out, optionally via an agent), **Search LocalMind Documents**, and **New LocalMind Chat**. Unlike the URL scheme these return their result, so the answer can feed the rest of a shortcut
- Tool transcripts — the tools an answer ran are kept with the message and shown as expandable chips with what was sent, what came back, and how long it took
- Knowledge base **Rebuild index** — re-chunk and re-embed in place, including switching embedding model without deleting your documents first

### Fixed
- **Tool calls now work end to end.** Results are fed back to the model so it can answer using them; previously the raw output was appended to the message and the model never saw it
- Streamed tool calls from OpenAI-compatible servers are reassembled correctly (they arrive as fragments; each fragment was being treated as a complete call, producing empty names and truncated arguments)
- Retrieval no longer silently drops matches: all embeddings on a machine now share one vector space, chunks overlap so a fact split across a boundary is still findable, and keyword (BM25) results are blended with semantic ones so exact terms like error codes and filenames match
- Token counts and tokens/sec come from the model server when it reports them, instead of always being estimated
- MCP requests all time out rather than only the initial handshake, so a silent server can't wedge a tool call indefinitely
- Concurrent MCP approval prompts queue instead of overwriting each other
- Cross-chat memory re-embeds edited turns and persists title changes

### Added
- First-run onboarding: backend detection, one-click Ollama guidance, and a model recommendation sized to your Mac's memory
- In-app auto-updates via Sparkle ("LocalMind → Check for Updates…"), with the appcast generated by the release workflow
- Landing page (GitHub Pages), comparison doc, community agent & pipeline packs, and a launch checklist
- Weekly automations with a day-of-week picker
- Pipeline sharing as JSON (export/import from Agents settings)
- Prompt snippet template variables: `{{date}}`, `{{time}}`, `{{clipboard}}`
- Knowledge base: "Sync now" for watched folders, document filtering and newest-first sorting; re-importing a document replaces it instead of duplicating chunks
- Voice mode's pause-to-send window is adjustable (1.0–4.0s)
- `PRIVACY.md`, `ROADMAP.md`, and this changelog

### Fixed
- Conversations that decompress past 10MB now load (the decompression buffer grows on demand instead of being fixed)
- Persistence writes are atomic and log failures instead of silently dropping them
- Merging conversations orders the combined messages chronologically
- The bubble window's conversation picker can always show the current selection
- The automations timer no longer ticks while no automation is enabled
- "Clear All Chat History" asks for confirmation first

## 0.9 — 2026-07-19

### Added
- Projects: workspaces that group conversations with a default agent, standing context, and knowledge collections
- Agent pipelines: reusable chains where each step transforms the previous step's output
- Automations: scheduled prompts delivering results as unread conversations
- Hands-free voice mode: listen → generate → speak, fully on-device
- Prompt snippet library
- Homebrew cask and release/distribution docs

## Earlier

- Multi-agent system: agents, agent teams, debate mode, auto-routing
- Background generation with unread indicators
- Knowledge base with citations, watched folders, OCR, and Ollama or Apple embeddings
- Per-turn variant navigator and RAG citations
- Ollama tool-call support, MCP server catalog
- Vision, file attachments, multi-format export, cross-chat memory, focus timer
